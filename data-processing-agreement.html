1. Definitions

Defines key terms including Breach Event, Personal Data, Data Subject, Processing, Services and Subprocessor.

2. Purpose

Sets the conditions under which the Processor handles Personal Data on behalf of the Controller.

3. Compliance with Laws

The Processor follows applicable data privacy laws and notifies the Controller if it can no longer comply; the Controller remains responsible for data accuracy and consent.

4. Ownership of Data

Personal Data remains the Controller's property unless the main agreement states otherwise.

5. Duration of Processing

Obligations run from signing of the main agreement until the Processor stops providing Services.

6. Types of Data

The Processor handles the categories of data listed in Schedule 1.

7. Instructions for Processing

Processing is limited to the agreement and documented instructions; the Processor flags instructions that may violate the law.

8. Data Subject's Rights

The Processor passes along data subject requests promptly and helps the Controller respond.

9. International Transfers

No transfer or disclosure of Personal Data outside the United States without the Controller's written approval, except where required by law.

10. Data Protection Impact Assessments

The Processor assists with impact assessments and provides information on transmission, storage, encryption and destruction.

11. Confidentiality

Both parties keep Personal Data confidential; the Processor binds authorized staff to confidentiality duties.

12. Liability

Mutual indemnification for breaches, with liability limited to damages directly caused and subject to the main agreement's limits.

13. Data Security

Appropriate technical and organizational safeguards against loss, unauthorized access and similar risks.

14. Breach Notification

Prompt reporting of any Breach Event involving the Controller's data.

15. Limitations on Use

Personal Data is used only to perform the main agreement.

16. Subcontractor Requirements

Subcontractors only with prior written consent and a written contract flowing down the same obligations.

17. Destruction or Return of Data

Secure deletion or return within 30 days of request or termination, unless law requires retention.

18. Audits and Compliance

The Controller or its auditor may inspect compliance with reasonable notice, limited to relevant systems and documents.

19. Recordkeeping Obligations

Accurate processing records, provided to the Controller within 30 days of request.
